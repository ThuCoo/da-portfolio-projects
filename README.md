<h2> Contents </h2>

**This repo contains exercises demonstrating a different skill on a
different dataset:**

1. **Data Exploration using SQL - Covid Dataset**  
   Explores Covid-19 deaths and vaccinations data with SQL to identify trends in cases, deaths, vaccination rates, and infection percentages.

2. **Visualization using Tableau - Resulting Dataset from 1**  
   Turns the Covid-19 analysis results into interactive Tableau dashboards that highlight global and regional pandemic trends.

- [Tableau Dashboard](https://public.tableau.com/views/DAPortfolioProject_17895512379650/CovidDashboard?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

3. **Data Cleaning using SQL - Nashville Housing Dataset**  
   Cleans and standardizes Nashville housing records by formatting dates, splitting address fields, populating missing values, and removing duplicates.

4. **Correlation using Python - Movies Dataset**  
   Uses Python to investigate relationships between movie attributes, including budget, gross revenue, ratings, votes, and other factors.

5. **Amazon Web Scraping using Python**  
   Collects product information from Amazon and saves the results for analysis, providing practice with web scraping and structured data extraction.

6. **Automating Crypto Website API Pull using Python**  
   Retrieves cryptocurrency market data through an API and automates repeated data collection so price changes can be monitored over time.
